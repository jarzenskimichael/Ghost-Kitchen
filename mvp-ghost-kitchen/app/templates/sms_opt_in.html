MESSAGING DISCLOSURE

SMS Program.

How MVP Ghost Kitchen currently uses text message notifications.

Chef MJs Feel Good BBQ LLC, doing business as Merriman Valley Pizza

MVP Ghost Kitchen is operated by Chef MJs Feel Good BBQ LLC, doing business as Merriman Valley Pizza ("MVP").

Organizer notifications only

The current MVP Ghost Kitchen SMS program is an internal operational notification service. It sends administrative alerts to the program organizer at the mobile number the organizer directly provided and configured for this purpose.

The organizer's consent is provided directly to MVP by supplying the destination number for operational alerts and requesting that SMS notifications be enabled. The number is not collected from public applicants for SMS marketing or enrollment.

Applicants and food-business operators are not currently enrolled in this SMS program and do not receive text messages through this application. Submitting a Ghost Kitchen application does not constitute consent to receive SMS messages.

Messages may include notices about new applications and application approvals. Message frequency varies with program activity. Message and data rates may apply.

To stop organizer alerts, the organizer can contact MVP and request that SMS notifications be disabled or that the destination number be removed from the service configuration.

If MVP later introduces text notifications for applicants or operators, it will first provide a separate, clear opt-in process describing the messages and obtain consent before sending those messages.
